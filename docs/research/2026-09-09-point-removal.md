# 토스포인트 기능 정리

2026-09-09 기존 공간까지 포함해 포인트 기능 정리를 완료했다. 후속 배포 요청으로 콘솔 업로드를 완료했다(`20260909-332`, `CREATED`). 검토 요청·공개 출시는 실행하지 않았다. [배포 기록](../deployments/2026-09-09-point-removal.md)을 참조한다. 사용자가 출시했다고 알린 이전 버전에는 지급 경로가 남아 있다.

일일 적립·잔액 수령, 주간 보상 계산·수령, 프로모션 SDK 호출 모듈, 포인트 전용 보상형 광고 및 미리 로드를 제거했다. 피드·마이로그·순위의 수령 버튼과 예상 보상, 미션 5원 안내, 사용법·서비스 설명·환경 예시도 정리했다. 홈 진입 링크는 ‘기존 공개 기록’으로 바꿨다.

기존 공개 기록, 커뮤니티, 순위 점수와 젤리·꾸미기는 유지한다. 과거 로컬 포인트 잔액과 수령 이력은 읽거나 변경하지 않으며 삭제하지 않는다. 서버 데이터와 콘솔 프로모션 설정도 변경하지 않았다.

검증: TypeScript 포함 프로덕션 빌드 성공, 단위 테스트 9개 및 브라우저 시나리오 12개 통과. 기존 잔액 47원이 있는 모의 연동 계정으로 피드·마이로그·순위에 진입해 포인트 수령 UI 부재, 젤리 접근, 과거 잔액·수령 이력 보존을 확인했다. QA의 Supabase 요청은 모두 가로채 실제 지급·운영 데이터 쓰기를 방지했다. 앱 소스의 지급·보상형 광고 호출이 없고, 배포 아카이브에서 기존 프로모션 코드·전용 광고 ID가 제거됐으며 dist 파일과 아카이브 파일이 일치함을 확인했다. 공용 SDK 내부의 미사용 기능 정의는 포함될 수 있으나 앱의 지급 호출은 없다.
